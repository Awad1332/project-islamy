# نظام التصميم — ABAYA OS Design System

المبدأ: **"أسهل من السهل"** — كل شاشة تجيب على سؤال واحد، وتعرض إجراءً رئيسياً واحداً، وتخفي ما لا يحتاجه التاجر الآن.

## 1. وضعان للعرض: بسيط / احترافي

| | بسيط (الافتراضي) | احترافي |
|---|---|---|
| القائمة | 8 أقسام مسطّحة: الرئيسية، الطلبات، المرتجعات، العميلات، الرسائل، العبايات، المقاسات، الإعدادات | كل الوحدات مجمّعة (البيع · الكتالوج · النمو · المتجر) |
| إضافة عباية | معالج بثلاث خطوات بأزرار جاهزة | المحرر الكامل + مولّد المتغيرات |
| الحقول | الأساسية فقط؛ الباقي خلف «خيارات إضافية» | كل الحقول (SKU، SEO، التكلفة، السعر قبل الخصم…) |
| المصطلحات | لغة يومية («الكمية»، «خيار») | المصطلحات المهنية |

يُحفظ الوضع على الجهاز (`localStorage`) ويُبدَّل من أعلى الشاشة. هو عرض فقط — الصلاحيات يفرضها الخادم دائماً.

## 3. الأيقونات — أيقونة واحدة لكل مفهوم

مصدر واحد: `apps/web/src/components/icons.tsx` (`ICONS`). نفس الأيقونة في القائمة، ورأس الصفحة، والإجراءات السريعة، والشريط السفلي.
الأسلوب: خطوط lucide بسمك **1.75** وأطراف دائرية، مع أيقونة عباية مخصّصة (`AbayaIcon`) للمنتجات.
رأس كل صفحة يلتقط أيقونته تلقائياً من المسار (`iconForPath`) فلا يمكن أن تختلف.

## 4. نمط كل صفحة

```
[أيقونة المفهوم]  العنوان                         [إجراء رئيسي واحد]
                   سطر يشرح الصفحة
──────────────────────────────────────────────────────────────
فلاتر بسيطة (بحث + حالة)
المحتوى داخل بطاقات (Card)
حالة تحميل (هياكل) · حالة خطأ (مع "إعادة المحاولة") · حالة فراغ (مع الخطوة التالية)
```

* زر رئيسي واحد لكل شاشة (فحمي)؛ الإجراء «المميّز» (حفظ نهائي، تشغيل) بالذهبي.
* الحالات ملوّنة بمعنى ثابت: أخضر = تم، كهرماني = ينتظركِ، أحمر = مشكلة، ذهبي = قيد العمل.
* الحقول الثانوية خلف `MoreOptions` («خيارات إضافية») — مفتوحة تلقائياً في الوضع الاحترافي.
* الأهداف اللمسية ≥ 44px (الأزرار الكبيرة، الشرائح `ChipPicker`).
* رسائل الخطأ مترجمة وبجمل مفهومة، مرتبطة بالحقل نفسه.

## 5. الجوال

* شريط سفلي: الرئيسية · الطلبات · **＋** · العبايات · العميلات.
* زر **＋** يفتح ورقة «إضافة سريعة»: عباية / طلب / عميلة.
* القائمة الكاملة من زر ☰.

## 6. الدخول والبدء

* التسجيل: **4 خانات** (اسم المتجر، الاسم، البريد، كلمة المرور). رابط المتجر يُنشأ تلقائياً.
* زر إظهار/إخفاء كلمة المرور، ولوحة مفاتيح مناسبة لكل حقل على الجوال.
* بعد الدخول: تحية + 4 إجراءات كبيرة + «يحتاج انتباهكِ» + قائمة إعداد المتجر.
* التشغيل التقني: أمر واحد `./start.sh` (انظري [DEPLOYMENT.md](./DEPLOYMENT.md)).
