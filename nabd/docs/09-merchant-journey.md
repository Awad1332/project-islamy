# 09 — رحلة التاجر: من صفر طلب إلى متجر محترف

## 1. ما الذي تغيّر في نبض؟
نبض صار يخدم **كل تاجر في سلة**، من المتجر اللي لسه ما باع ولا طلب إلى المتجر الكبير.
التاجر يُعامل **كطالب**: يمشي في رحلة بمراحل، كل مرحلة لها هدف بعدد الطلبات، ومهام بسيطة، وشرح لكل مهمة، ونقاط تبيّن تقدمه.

**كيف تتصل الرحلة بفكرة نبض الأصلية؟**
- من 0 إلى 100 طلب: **الرحلة** (تعليم وتأسيس وتسويق أساسي). البيانات هنا قليلة، فالأساسيات أهم من التحليل.
- من 100 طلب فأكثر: يفتح **نبض الذكي** (محرك الفرص والتجارب والذاكرة)، لأن البيانات صارت كافية لاستنتاجات موثوقة.
- كذا صار عندنا منتج واحد يكبر مع التاجر، والتاجر ما يطلع منه لما يكبر.

## 2. المراحل السبع

| المرحلة | الاسم | الهدف | التركيز |
|---------|-------|-------|---------|
| 1 | التأسيس | قبل أول طلب | الهوية، صفحات الثقة، التوثيق، الدفع والشحن، أول 10 منتجات، حسابات السوشيال |
| 2 | أول الطريق | من 1 إلى 10 طلبات | إعلان الافتتاح للمعارف، واتساب للأعمال، ستوري يومي، التقييمات، محتوى التغليف |
| 3 | بناء الثقة | من 10 إلى 20 طلبًا | السلات المتروكة، تحسين أكثر المنتجات زيارة، ريلز أسبوعية، كوبون الطلب الثاني |
| 4 | الانتشار | من 20 إلى 50 طلبًا | أول إعلان ممول صغير ومقاس، مؤثر صغير بكود، حد الشحن المجاني، تقويم محتوى شهري |
| 5 | الثبات | من 50 إلى 100 طلب | العروض المجمعة، حملات المواسم، هامش الربح |
| 6 | النمو الذكي | من 100 إلى 300 طلب | يفتح نبض الذكي: الفرص، التجارب، إعادة التنشيط |
| 7 | الاحتراف | 300 طلب فأكثر | الفريق، التنبيهات اليومية، جلسة شهرية مع خبير |

**لماذا المراحل ليست كل 10 طلبات؟** في البداية نعم: 0، 1، 10، 20. هنا كل طلب فرق كبير. بعد 50 طلبًا، القفز كل 10 طلبات يصير مملًا ولا يغيّر المهام. فالمراحل تصير أوسع كلما كبر المتجر.

## 3. المهام (النقاط)

كل مهمة تحتوي:
- **العنوان**: فعل واضح (مثل «فعّل تذكير السلات المتروكة»).
- **الفئة**: المتجر / المحتوى / السوشيال / التسويق / التشغيل.
- **ليش مهمة؟**: جملة أو جملتان بلغة بسيطة.
- **كيف تسويها؟**: 3 خطوات قصيرة.
- **دليل سلة خطوة بخطوة** (إن وجد): أين تضغط بالضبط في لوحة سلة.
- **سوّها لي** (إن أمكن): نبض ينفّذها تلقائيًا عبر سلة، مثل إنشاء كوبون.
- **النقاط**: من 10 إلى 30 حسب الجهد والأثر.
- **طريقة التحقق**: تلقائي من سلة (مثل عدد المنتجات، طرق الدفع، الصفحات)، أو التاجر يضغط «سويتها».

**قواعد النقاط**:
- النقاط لتحفيز التعلم فقط. **الانتقال بين المراحل يكون بعدد الطلبات الحقيقي من سلة** مع إكمال المهام الأساسية، حتى لا تصير اللعبة منفصلة عن الواقع.
- شارات عند إنهاء كل مرحلة (لاحقًا: شارة تظهر في المتجر مثل «متجر موثوق من نبض» بعد مراجعة).

المحتوى الكامل لكل المهام موجود في النموذج التفاعلي `preview/nabd-journey.html`.

## 4. أدلة سلة خطوة بخطوة

- تظهر **داخل نبض** كخطوات مصورة: شريط جانبي مبسط للوحة سلة، والزر المطلوب مظلّل.
- زر **«افتح الصفحة في سلة»** ينقل التاجر للصفحة المطلوبة مباشرة.
- **لا نستطيع التعديل داخل لوحة سلة نفسها**، فالشرح يكون في نبض بجانبها.
- الأدلة في النسخة الأولى: إنشاء كوبون، صفحات السياسات، طرق الدفع، إضافة منتج، السلات المتروكة، الشحن والشحن المجاني.
- **صيانة مستمرة**: لوحة سلة تتغير. نحتاج في لوحة الإدارة قسمًا لتعديل الأدلة وصورها بدون برمجة، ومراجعة شهرية لها.
- **ميزة الباقات**: المجانية 3 أدلة، الأساسية كل الأدلة، النمو يضيف «سوّها لي» تلقائيًا (الكوبونات والعروض عبر Salla API).

> تنبيه: أسماء القوائم في النموذج للتوضيح. يجب مطابقتها مع لوحة سلة الحالية قبل الإطلاق.

## 5. المحتوى والسوشيال ميديا

### صانع المحتوى
- أفكار منشورات أسبوعية مبنية على: منتجات المتجر، المرحلة الحالية، المواسم السعودية (يوم الراتب، رمضان، العيد، اليوم الوطني، الجمعة البيضاء).
- نص منشور جاهز بلهجة قريبة من العميل، مع الهاشتاقات، وزر نسخ.
- **في النسخة الأولى: نصوص وأفكار فقط**. توليد الصور والفيديو لاحقًا (مكلف، وموجود عند منافسين كثير).
- الحد الشهري حسب الباقة (20 / 60 / غير محدود).

### مراقبة السوشيال ميديا
| المنصة | الممكن | ملاحظة |
|--------|--------|--------|
| إنستقرام | ✅ حساب التاجر: المنشورات، الوصول، التفاعل، المتابعون | يحتاج حساب أعمال أو صانع محتوى مربوط بصفحة فيسبوك (Instagram Graph API) |
| تيك توك | ✅ حساب التاجر عبر واجهات تيك توك للأعمال | يحتاج موافقة تطبيق من تيك توك |
| سناب شات | ⚠️ محدود | بيانات الحساب العام محدودة. الإعلانات ممكنة عبر واجهة سناب الإعلانية |
| إكس | ⚠️ مكلف | واجهة إكس مدفوعة، فهي مؤجلة |

**الربط الأهم**: نربط الروابط المنشورة (رابط البايو والكوبونات) بمتتبع نبض في المتجر، فنعرف أي منشور جاب **زيارات وطلبات فعلية**، وليس إعجابات فقط.

مراقبة «نشاطك»: هدف منشورات أسبوعي حسب المرحلة، ونسبة الالتزام، وأفضل وقت نشر لمتابعيك.

## 6. الخطة التسويقية الشهرية
- خطة لكل شهر: هدف (بعدد الطلبات)، ميزانية مقترحة، 4 أسابيع لكل أسبوع موضوع ومهام.
- مبنية على: المرحلة، المنتجات الأكثر مبيعًا، المواسم، ونتائج الشهر السابق من الذاكرة.
- الأسبوع الأول مجاني للجميع كإعلان للباقة. الخطة كاملة في باقة النمو.

## 7. مراقبة تغييرات المتجر
نبض ينتبه لكل تغيير عبر Webhooks ولقطات يومية: تغيّر سعر، نفاد مخزون، منتج جديد ناقص البيانات، إخفاء تصنيف، منتج رابح مخفي. ويقول للتاجر إذا كان للتغيير أثر محتمل، ويسجله في ذاكرة المتجر.

**لماذا تغيرت الأسعار عن الوثيقة 07 (149 / 349 / 799)؟** الشريحة صارت تشمل المتاجر الجديدة اللي ما عندها دخل بعد، فنحتاج مدخلًا أرخص. تسعير المتاجر الكبيرة ممكن يبقى بحدود الطلبات داخل الاحترافية أو باقة مؤسسات لاحقًا.

**الجلسة مع الخبير** فرصة شراكة مع «خبراء المنصات»: الوكالة تقدم الجلسات، ونبض يجهز لها أرقام المتجر وخطته قبل الجلسة.

## 9. مساحة الإعلان داخل لوحة التاجر
- **مكان واحد فقط** أعلى الصفحة الرئيسية، يعلن عن ميزة من الباقة الأعلى مباشرة (المجانية ← الأساسية ← النمو ← الاحترافية).
- **مرتبط بمرحلة التاجر** وليس عامًا. مثال لتاجر في المرحلة 3 على الباقة الأساسية: «خطتك التسويقية لشهر أكتوبر جاهزة».
- **قابل للإغلاق**، ولا يرجع قبل 7 أيام.
- **معاينة مقفلة**: الأقسام المدفوعة تظهر للتاجر بشكل ضبابي مع زر ترقية، فيرى وش بياخذ قبل ما يدفع.
- **عيّنة مجانية**: مثل الأسبوع الأول من الخطة التسويقية.
- يُدار من **لوحة الإدارة** (قسم جديد: «إعلانات داخل التطبيق»): النص، الشريحة المستهدفة (الباقة، المرحلة)، المدة، وقياس الضغطات والترقيات.
- حد أقصى: إعلان واحد ظاهر في نفس الوقت، ولا نوافذ منبثقة تقطع شغل التاجر.

## 10. إضافات على قاعدة البيانات

```sql
create table journey_levels (
  n int primary key, name_ar text not null, goal_ar text,
  orders_from int not null, orders_to int
);

create table journey_tasks (
  id text primary key, level_n int references journey_levels(n),
  category text not null,            -- store | content | social | market | ops
  title_ar text not null, why_ar text not null, how_ar jsonb not null,
  points int not null, guide_key text, auto_check text,   -- اسم فحص تلقائي من سلة إن وجد
  required_plan text, sort_order int, active boolean default true
);

create table store_task_progress (
  store_id uuid not null, task_id text not null references journey_tasks(id),
  status text not null default 'todo',   -- todo | done | skipped
  verified_by text,                       -- auto | merchant
  completed_at timestamptz,
  primary key (store_id, task_id)
);

create table salla_guides (                -- تُعدّل من لوحة الإدارة بدون برمجة
  key text primary key, title_ar text, steps jsonb not null,  -- نص + صورة + عنصر مظلل
  salla_deep_link text, auto_action text,  -- مثل create_coupon
  verified_at date                         -- آخر مراجعة مقابل لوحة سلة
);

create table social_accounts (
  id uuid primary key default gen_random_uuid(), store_id uuid not null,
  platform text not null,                  -- instagram | tiktok | snapchat
  handle text, token_enc bytea, status text, connected_at timestamptz
);

create table social_daily_metrics (
  account_id uuid not null, day date not null,
  followers int, posts int, reach int, engagement int, store_visits int, orders int,
  primary key (account_id, day)
);

create table content_items (
  id uuid primary key default gen_random_uuid(), store_id uuid not null,
  planned_for date, format text,           -- reel | story | post
  idea_ar text, caption_ar text, status text  -- idea | ready | published
);

create table marketing_plans (
  id uuid primary key default gen_random_uuid(), store_id uuid not null,
  month date not null, goal jsonb, budget_min int, budget_max int, weeks jsonb not null
);

create table in_app_promos (               -- إعلانات داخل لوحة التاجر
  id uuid primary key default gen_random_uuid(),
  title_ar text, body_ar text, target_plan text, target_levels int[],
  cta_plan text, starts_at timestamptz, ends_at timestamptz,
  impressions int default 0, clicks int default 0, upgrades int default 0
);
```

## 11. التأثير على الخطة (90 يومًا)
الإضافات كبيرة، فنرتبها كذا:
- **مع الإطلاق**: المراحل 1 إلى 5 بمهامها، النقاط، 6 أدلة سلة، صانع المحتوى (نصوص)، مساحة الإعلان، الباقات الأربع.
- **بعد الإطلاق بشهر**: ربط إنستقرام، الخطة التسويقية الشهرية، مراقبة تغييرات المتجر.
- **بعدها**: تيك توك، «سوّها لي» للعروض، الجلسات مع الخبراء، الشارات في المتجر.
- **نبض الذكي** يبقى كما في الخطة، لكنه يُفتح للمتاجر من 100 طلب.

**المخاطرة الأهم**: المحتوى التعليمي وأدلة سلة يحتاجون **كاتب محتوى وصيانة مستمرة**، وليس برمجة فقط. لازم يكون في الفريق شخص مسؤول عن المحتوى من البداية.
