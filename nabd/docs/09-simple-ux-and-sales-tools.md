# 09 — التجربة المبسطة، الهوية، وأدوات البيع

## 1. الهدف
أي تاجر يعرف يقرأ بس، يفتح نبض ويفهم في أقل من دقيقة: **وش صار؟ وش أسوي؟ وش النتيجة؟**
نبض هنا يتصرف كأنه **مدير متجر ومسوّق** يجلس جنبك، ويكلمك بلهجتك.

## 2. قواعد التجربة المبسطة (إلزامية على كل شاشة)

| القاعدة | التطبيق |
|---------|---------|
| فكرة وحدة في كل بطاقة | عنوان واحد + جملة شرح وحدة + رقم واحد + أزرار |
| كل شي له أيقونة كبيرة | اللي ما يقرأ بسرعة يفهم من الصورة واللون |
| ثلاث أنواع بطاقات فقط | 💡 **نصيحة** (بنفسجي) · ⏳ **قرار ينتظرك** (ذهبي) · 🏆 **نتيجة** (أخضر) · وتنبيه **انتبه** (أحمر) للأشياء المستعجلة |
| الأزرار أفعال واضحة | «سوّها لي»، «ذكّرني بكرة»، «ما تناسبني»، «كمّله»، «وقّفه» |
| لا مصطلحات | ممنوع: تحويل، AOV، Conversion، Segment، KPI. نقول: «ناس تشوفه وقليل يشترونه»، «الطلب الواحد صار أكبر» |
| الأرقام بالريال | ما نقول «+12.8%» لحالها. نقول «الزبون صار يدفع 17 ريال زيادة في كل طلب» |
| «سوّها لي» يسوي أغلب الشغل | نجهز الكود والرسالة والشريحة، والتاجر يضغط زر واحد |
| زر «اسمعها» | يقرأ البطاقة بالصوت (للي يفضل يسمع) |
| زر تكبير الخط | في أعلى كل شاشة |
| أربع صفحات فقط | الرئيسية · النصايح · الأدوات · النتايج |
| الصدق | كل رقم متوقع يكتب جنبه «تقريبًا، مو مضمون، بس نقيسه لك» |

## 3. دورة «نصيحة ← قرار ← نتيجة»

```
💡 نصيحة: «عندك 214 زبون ما رجعوا»
      │  [سوّها لي]  [ذكّرني بكرة]  [ما تناسبني → ليش؟]
      ▼
⚙️ نبض يجهز: كود خصم + رسالة + قائمة الزباين (مع مجموعة ما نرسل لها للمقارنة)
      │  [أرسلها]
      ▼
⏳ بعد أسبوعين — قرار ينتظرك: «الرسالة رجعت 13 زبون. تكمّل؟»
      │  [كمّله]  [وقّفه]
      ▼
🏆 نتيجة: «+1,940 ريال تقريبًا» ← تنحفظ في ذاكرة المتجر ← النصيحة الجاية أذكى
```

## 4. دليل الكتابة باللهجة السعودية

| بدل | نكتب |
|-----|------|
| مرحبًا بك | هلا والله / هلا فيك |
| انخفضت المبيعات | البيع نزل |
| معدل التحويل منخفض | ناس كثير تشوفه وقليل يشترونه |
| هل ترغب في المتابعة؟ | تكمّل؟ |
| تم بنجاح | تم / ابشر / انرسلت! |
| لاحقًا | بعدين / مو الحين |
| نوصي بـ | ننصحك / نبض ينصحك |
| العملاء غير النشطين | زباين ما رجعوا لك |
| المخزون منخفض | بيخلص عليك |

**نبرة الكلام**: قريبة ومحترمة، مثل أخ خبير يكلمك. بدون مبالغة ولا «ترند». ونتجنب الكلام الركيك والكلمات الإنجليزية.

## 5. الهوية البصرية

| العنصر | القيمة | ملاحظة |
|--------|--------|--------|
| اللون الأساسي | بنفسجي `#5B2BA6` | لون نبض (كما طلبت) |
| لون القرار | ذهبي `#E9A91E` | للقرارات والجوائز |
| لون النتيجة | أخضر `#1E8A52` | |
| لون التنبيه | أحمر `#C0392B` | للمستعجل فقط |
| الخلفية | بنفسجي فاتح جدًا `#F6F3FB` | |
| خط العناوين | **Tajawal** | من أكثر الخطوط العربية انتشارًا في المتاجر والتطبيقات السعودية |
| خط النصوص | **Almarai** | خط سعودي الأصل (صُمم لشركة المراعي)، واضح جدًا على الجوال |

> **ملاحظة عن سلة**: الهوية الحالية لسلة مبنية على الأخضر المائل للأزرق الغامق مع لون فاتح قريب من النعناعي، وليس البنفسجي. البنفسجي يعطي نبض **شخصية مستقلة** ويبان مختلفًا جنب سلة في متجر التطبيقات، وهذا أفضل من تقليد هويتها. ولا نستخدم شعار سلة أو ألوانها بطريقة توحي أننا منتج رسمي منها.

## 6. أدوات زيادة المبيعات

الأدوات تنضاف لمتجر التاجر بضغطة عبر **App Snippet** (نفس السكربت الذي يجمع الزيارات)، وتتحكم فيها من صفحة «الأدوات». **الفرق عن التطبيقات المنافسة**: نبض لا يكتفي بتشغيل الأداة، بل **يقترحها في الوقت المناسب** (من الفرص) و**يقيس وش جابت** (من التجارب).

| الأداة | وش تسوي | متى ينصح فيها نبض | وش نقيس |
|--------|---------|-------------------|---------|
| نافذة ترحيب (Popup) | خصم لأول طلب مقابل رقم الجوال أو الإيميل | زوار جدد كثير وقليل منهم يشتري | أرقام جديدة، وطلبات بكود الترحيب |
| عجلة الحظ | الزائر يلف ويكسب خصم أو شحن مجاني | متاجر الهدايا والموضة، والزوار الجدد | نسبة من لف، ومن استخدم الجائزة |
| «أحد اشترى قبل شوي» | تنبيه بطلبات حقيقية (المدينة فقط بدون أسماء) | منتجات عليها زيارات والناس مترددة | الشراء بعد ظهور التنبيه |
| شريط الشحن المجاني | «باقي لك 21 ريال وتحصل شحن مجاني» | طلبات كثيرة قريبة من حد الشحن | متوسط قيمة الطلب |
| عداد العرض | عداد تنازلي لعرض حقيقي | عند وجود عرض له نهاية فعلية | المبيعات خلال فترة العرض |
| أعلمني إذا توفر | الزبون يترك رقمه لما ينفد المنتج | منتج يبيع زين وبيخلص | عدد المنتظرين، ومن اشترى بعد رجوع المنتج |
| «ناس اشتروا معه» | يقترح منتج يكمّل اللي في السلة | من تحليل المنتجات اللي تنشرى مع بعض | نسبة الإضافة، ومتوسط الطلب |
| زر واتساب | زر ثابت للتواصل المباشر | متاجر المنتجات اللي تحتاج أسئلة | عدد الضغطات |

**عن «نوتي موني»**: فهمتها على أنها أداة تنبيهات «فلان اشترى» أو «أعلمني إذا توفر». الاثنين موجودين في القائمة. إذا تقصد أداة ثانية، قل لي.

### قواعد لازم نلتزم فيها
1. **لا تنبيهات وهمية**: «أحد اشترى» يعرض طلبات حقيقية فقط. التنبيهات المزيفة تضلل المستهلك، وممكن تعرّض التاجر لمخالفة من وزارة التجارة.
2. **لا عدادات مزيفة**: العداد لازم يكون على عرض له نهاية حقيقية، مو عداد يرجع يبدأ كل ما فتح الزبون الصفحة.
3. **عجلة الحظ**: كل الجوائز حقيقية وتُعطى فعلًا، واللف مجاني بدون شرط شراء، وكل الشرائح فيها جائزة (بدون «حظ أوفر» المخادع).
4. **الأرقام اللي تُجمع** (جوال أو إيميل من النافذة) ملك للتاجر، ويوافق الزبون صراحة على استلام الرسائل.
5. **ما نبطئ المتجر**: كل أداة خفيفة، وتتحمّل بعد تحميل الصفحة.
6. **ما نزعج الزبون**: النافذة مرة وحدة لكل زائر، والعجلة ما تطلع مع النافذة بنفس الوقت.

## 7. الأولويات
- **مع الإطلاق**: شريط الشحن المجاني، أعلمني إذا توفر، ناس اشتروا معه (الثلاث مرتبطة مباشرة بفرص نبض وسهلة القياس).
- **بعد الإطلاق بشهر**: نافذة الترحيب، «أحد اشترى»، زر واتساب.
- **لاحقًا**: عجلة الحظ، عداد العرض.

**السبب**: الأدوات اللي تخدم دورة «نصيحة ← قرار ← نتيجة» أولًا. عجلة الحظ جذابة في التسويق وموجودة عند منافسين كثير، لكن أثرها على الربح أصعب في القياس، وممكن تعوّد الزبون على الخصم.
