# 06 — Dashboard Wireframes · UX Flows · Daily Brief · Weekly Report

## مبادئ UX
1. **Mobile-first**: أغلب التجار يفتحون من الجوال صباحًا. كل شاشة تعمل بعرض 375px.
2. **سؤال واحد لكل شاشة**: الرئيسية = "ماذا أفعل اليوم؟"، الفرصة = "هل أبدأ؟"، التجربة = "هل نجح؟".
3. **كل رقم معه سياق**: مقارنة (مقابل الأسبوع الماضي/نفس اليوم الأسبوع الماضي) + هل هذا طبيعي؟
4. **لا رسوم بيانية في الرئيسية** إلا Sparkline صغير. الرسوم داخل صفحة الفرصة كدليل فقط.
5. **حالة البيانات ظاهرة دائمًا**: "آخر تحديث قبل 12 دقيقة" / "بيانات الزيارات تبدأ من 14 سبتمبر".
6. الأرقام: ريال سعودي، أرقام لاتينية (1,250) افتراضيًا مع خيار الأرقام العربية.

**قواعد الصفحة الرئيسية**:
- إن لم توجد مشكلة → قسم "تحتاج انتباهك" **يختفي** (لا نملأ الفراغ).
- إن كان التحويل غير متاح → البطاقة تقول: "يبدأ القياس خلال X يومًا" بدل 0%.
- "طبيعي/غير طبيعي" يُحسب من تباين المتجر التاريخي (±2σ لنفس يوم الأسبوع)، لا من النسبة فقط.

## 7. UX Flows

### Flow 1 — التثبيت حتى أول فرصة
```
متجر تطبيقات سلة → [تثبيت] → موافقة الصلاحيات (سلة)
→ app.store.authorize → إنشاء حساب تلقائي → فتح نبض
→ أسئلة (4، قابلة للتخطي): فئة المتجر · هدفك الآن · هامش الربح التقريبي · هل لديك GA4؟
→ شاشة الاستيراد: "نقرأ آخر 90 يومًا..." (تقدم حي) + ماذا سنفعل ولماذا
→ [أول فرصة جاهزة] (هدف: < 15 دقيقة) → بطاقة الفرصة
→ إن لم تتوفر بيانات كافية: "متجرك يحتاج ~X طلبًا إضافيًا لنعطيك فرصًا موثوقة. في الأثناء: قائمة إعداد…"
```

### Flow 2 — من فرصة إلى تجربة
```
بطاقة الفرصة → [ابدأ التجربة]
→ شاشة إعداد (مملوءة مسبقًا): الفرضية · المقياس · المدة المقترحة (بعد فحص القوة) · معيار النجاح
→ (إعادة تنشيط) معاينة الشريحة: 171 مستهدف / 43 ضابطة (عشوائي)
→ أدوات التنفيذ: [إنشاء كوبون في سلة] [تصدير CSV للمستهدفين] [نسخ نص الرسالة]
→ [تأكيد البدء] → حدث في الذاكرة → متابعة يومية (بدون كشف النتيجة مبكرًا)
→ نهاية المدة → إشعار "النتيجة جاهزة" → شاشة النتيجة → [استمر / أوقف / عدّل / مدّد]
→ learnings + تحديث الفرص
```

### Flow 3 — رفض فرصة
```
[غير مناسب] → سبب → (غير دقيق) → "ما الخطأ؟" نص اختياري → تُقمع 60 يومًا + تُسجل للمراجعة
```

### Flow 4 — ربط وكالة
```
التاجر: الإعدادات → الفريق والوكالات → [دعوة وكالة] (بريد/رمز) → الوكالة تقبل
→ يظهر المتجر في المحفظة → التاجر يرى "خبراء المنصات لديها صلاحية مشاهدة" [إلغاء]
```

## 8. Daily Brief (منطق الترتيب)

المرشحون كل صباح: الشذوذات، الفرص الجديدة، نتائج التجارب، التحسنات المؤكدة، تنبيهات المخزون.

```
priority = severity × actionability × novelty × confidence
  severity      : الأثر بالريال نسبة للإيراد اليومي
  actionability : 1 إن كان هناك إجراء واضح، 0.3 إن كان "للعلم"
  novelty       : 0 إن ذُكر نفس الشيء خلال 3 أيام دون تغير
  confidence    : من حجم العينة
```
- حد أقصى 4 عناصر: ⚠️ مشكلة واحدة · 🔥 فرصة واحدة · 📈 تحسن واحد · 🎯 مهمة واحدة. أي خانة بدون مرشح قوي **تُحذف**.
- **Push/بريد** يُرسل فقط إذا وُجد عنصر `priority` فوق حد العتبة؛ حد أقصى 1 يوميًا و3 أسبوعيًا. غير ذلك: Brief داخل التطبيق فقط.
- **أمثلة تنبيه مقبول**: "طلبات أمس أقل من المعتاد بشكل غير طبيعي (−48% مقابل نفس اليوم في 4 أسابيع سابقة) ولا يوجد حدث مسجل يفسره."
- **مرفوض**: "المبيعات اليوم 3,500 ريال."
