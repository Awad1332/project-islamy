# تشغيل نبض على جهازك

## أسهل طريقة (بدون أي برامج)
1. فك ضغط الملف.
2. افتح مجلد `nabd`.
3. اضغط مرتين على **`index.html`**، وبيفتح في المتصفح.
4. اختر **لوحة التاجر** أو **لوحة الإدارة**.

## طريقة بسيرفر محلي (اختيارية)
تحتاج Python أو Node.js مثبت على جهازك.

- **ويندوز**: اضغط مرتين على `start.bat`.
- **ماك أو لينكس**: افتح الطرفية داخل المجلد واكتب:
  ```
  ./start.sh
  ```
بعدها افتح المتصفح على: **http://localhost:8080**

## ملاحظات
- الخطوط تتحمّل من Google Fonts، فتحتاج إنترنت عشان تطلع بنفس الشكل. بدون إنترنت تشتغل بخط الجهاز.
- اللوحتان نماذج تفاعلية ببيانات تجريبية، بدون ربط حقيقي مع سلة ولا قاعدة بيانات.
- محتوى المجلد:
  - `preview/`: لوحة التاجر ولوحة الإدارة
  - `docs/`: وثائق المنتج كاملة
  - `presentation/`: عرض الاجتماع
